# VÉRTICE — Site Básico (R$ 300)

Modelo inicial reutilizável para pequenos negócios. Este repositório é uma base de projeto, não um site publicado.

## Escopo
- Página única responsiva para celular e computador.
- Nome, descrição, serviços/produtos, horário e endereço editáveis.
- Botão de WhatsApp com mensagem pré-preenchida.
- Sem agendamento interno, carrinho ou pagamento on-line.
- Sem dependência de banco de dados.

## Stack planejada
Vite + React + CSS responsivo.

## Personalização por cliente
Substituir os dados de demonstração em `src/config.js`, atualizar cores e imagens e configurar o link de WhatsApp. Nunca publicar dados fictícios como se fossem reais.

## Publicação
Pode ser publicado em hospedagem estática compatível com Vite. Domínio, hospedagem, manutenção e eventuais custos de terceiros devem ser definidos na proposta comercial.

## Status
Estrutura inicial em desenvolvimento.

## Executar localmente

1. Instale Node.js LTS.
2. Execute `npm install`.
3. Execute `npm run dev` para desenvolvimento.
4. Execute `npm run build` para gerar a versão de produção em `dist/`.

## Antes de publicar
- Troque todos os dados de demonstração em `src/config.js`.
- Teste o WhatsApp em celular e computador.
- Use apenas fotos e textos autorizados e informações verdadeiras.
- Confira acessibilidade, responsividade e links.
- Não publique segredos, tokens ou credenciais no frontend ou no GitHub.
